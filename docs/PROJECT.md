# NexusCRM

## Overview

NexusCRM is an enterprise CRM and order-management platform designed
for organizations with sales, management, finance, support, and
administrative teams.

## Core Business Flow

Lead
→ Opportunity
→ Quote
→ Order
→ Payment
→ Fulfillment

Customers may additionally interact with support workflows.

## Users

### Administrator

Manages:

- users
- roles
- permissions
- products
- configuration

### Sales Agent

Manages:

- leads
- customers
- opportunities
- quotes
- orders

### Sales Manager

Manages:

- teams
- pipeline
- approvals
- sales reporting

### Finance

Manages:

- payments
- refunds
- financial reporting

### Support Agent

Manages:

- support tickets
- customer issues

## Non-Functional Goals

The application should demonstrate:

- transactional consistency
- concurrency control
- secure authorization
- scalable API design
- relational database design
- asynchronous processing
- automated testing
- observability
- maintainability
